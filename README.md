# Lógica de Programação

Este repositório tem como objetivo organizar as anotações e os conteúdos estudados na disciplina de Lógica de Programação durante a graduação em Ciência da Computação.

## Objetivo

Registrar os conhecimentos adquiridos durante as aulas, desenvolvendo o raciocínio lógico e a capacidade de criar algoritmos para resolver problemas computacionais.
